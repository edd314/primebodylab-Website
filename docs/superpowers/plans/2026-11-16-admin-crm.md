# Admin CRM Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `/admin`, a password-protected internal page on the existing PrimeBodyLab Next.js site where Eddie tracks clients, package balances, home/studio/corporate tags, follow-up reminders, and an activity log — fed both manually and automatically from the site's existing lead-capture routes.

**Architecture:** A new `src/app/admin/*` route tree, outside `src/app/[locale]/*` (English-only, no bilingual content). Access is gated by a single shared password, checked server-side, backed by a signed session cookie verified in `src/proxy.ts` (this project's middleware file — renamed from `middleware.ts` in this Next.js version). Data lives in three Postgres tables (`clients`, `packages`, `activity_log`) queried with plain SQL via `@vercel/postgres` — no ORM, matching the rest of the codebase. `src/app/api/subscribe/route.ts` and `src/app/api/corporate-lead/route.ts` each gain a best-effort write into `clients`/`activity_log`.

**Tech Stack:** Next.js 16.2.12 (App Router), React 19.2.4, TypeScript, Vitest, `@vercel/postgres`, Tailwind (existing design tokens: `bone`/`ink`/`sage`/`forest`/`line`/`muted`).

## Global Constraints

- **`cookies()` from `next/headers` returns a `Promise`** in this Next.js version (confirmed in `node_modules/next/dist/server/request/cookies.d.ts`) — always `await cookies()`. Likewise, page `params`/`searchParams` are `Promise`s — always `await` them (the rest of the codebase already does this; follow the same pattern).
- **React 19 renamed `useFormState` to `useActionState`** (imported from `'react'`, not `'react-dom'`). Use `useActionState` wherever a form needs to show a server action's returned error.
- **Edge-runtime isolation:** `src/proxy.ts` runs on the Edge runtime. Any module it imports — directly or transitively — must only use Web Crypto (`crypto.subtle`, which is a global, no import needed) and never Node's built-in `crypto` module (`createHash`, `timingSafeEqual`, etc.). This plan keeps that boundary as two separate files: `src/lib/crm/session.ts` (Edge-safe, imported by `proxy.ts`) and `src/lib/crm/password.ts` (Node-only, imported only by the login Server Action, never by `proxy.ts`).
- **No ORM.** All queries are plain SQL via `@vercel/postgres`'s `sql` tagged template, matching how the rest of this codebase has no ORM anywhere.
- **`/admin` is intentionally outside `src/app/[locale]`.** It is not subject to the site's `{de, en}` bilingual content rule or the `review.json` copy-approval gate (see the design doc's Non-goals). Build all `/admin` UI text directly in English, as plain strings — no `src/content/*.ts` entries needed.
- **The existing middleware matcher already covers `/admin`.** `src/proxy.ts`'s `config.matcher` excludes only `api|_next|_vercel|icon|apple-icon|opengraph-image|<files with an extension>` — `/admin/*` paths already reach the `proxy` function today (currently handled by the next-intl middleware it delegates to). This plan branches on `/admin` paths explicitly before delegating anything else to next-intl; no matcher change is needed.
- **Deviation from the design doc:** the design doc's data-model table lists `clients.name` as "required." In practice, a Welcome-popup-sourced lead has no name at creation time (the popup only ever collects an email) — making `name` required would make that integration impossible to satisfy honestly. `name` is nullable in the actual schema below; every place the UI displays a client falls back to `client.email`, then `` `Client #${id}` ``, if `name` is empty. Edding in a real name later is a normal edit on the client detail page.
- **Verification gate for every task:** `npx tsc --noEmit` and `npm run build` must both succeed, and `npm test` must show all tests passing, before a task is considered done. A pre-existing, unrelated failure already exists in `src/lib/__tests__/campaigns.test.ts` (a `ctaHref` property not in the `Campaign` type) — it predates this work and is out of scope; do not attempt to fix it, and don't let it block a task (confirm via `git status --short src/lib/__tests__/campaigns.test.ts` that you haven't touched it, same as earlier sessions did).
- **Commit messages:** every commit in this plan ends with the trailer `Co-Authored-By: Claude Sonnet 5 <noreply@anthropic.com>` — included in the commit command for each task below.
- **Rollout prerequisite:** Eddie must add Vercel Postgres to the Vercel project (and set `ADMIN_PASSWORD` + `ADMIN_SESSION_SECRET` env vars) before the DB-backed parts of this can run against production. Tasks 1–4 (pure logic) need none of this and can be fully tested locally. Tasks 5 onward touch the database and need either a local `POSTGRES_URL` (Vercel can provision a free local-dev connection string from the same integration) or deferred manual verification until Eddie has provisioned it — flagged again at Task 5.

// src/lib/crm/session.ts
export const COOKIE_NAME = 'admin_session';
export const MAX_AGE_SECONDS = 60 * 60 * 24 * 30; // 30 days

function requireSecret(): string {
  const secret = process.env.ADMIN_SESSION_SECRET;
  if (!secret) throw new Error('ADMIN_SESSION_SECRET is not set');
  return secret;
}

async function getKey(secret: string): Promise<CryptoKey> {
  return crypto.subtle.importKey(
    'raw',
    new TextEncoder().encode(secret),
    {name: 'HMAC', hash: 'SHA-256'},
    false,
    ['sign'],
  );
}

function toHex(buffer: ArrayBuffer): string {
  return Array.from(new Uint8Array(buffer))
    .map((b) => b.toString(16).padStart(2, '0'))
    .join('');
}

export async function createSessionToken(): Promise<string> {
  const issuedAt = Date.now().toString();
  const key = await getKey(requireSecret());
  const signature = await crypto.subtle.sign('HMAC', key, new TextEncoder().encode(issuedAt));
  return `${issuedAt}.${toHex(signature)}`;
}

export async function verifySessionToken(token: string | undefined | null): Promise<boolean> {
  if (!token) return false;

  const [issuedAt, signatureHex] = token.split('.');
  if (!issuedAt || !signatureHex) return false;

  const age = Date.now() - Number(issuedAt);
  if (!Number.isFinite(age) || age < 0 || age > MAX_AGE_SECONDS * 1000) return false;

  const key = await getKey(requireSecret());
  const expectedSignature = await crypto.subtle.sign('HMAC', key, new TextEncoder().encode(issuedAt));
  return toHex(expectedSignature) === signatureHex;
}
```

// src/lib/crm/password.ts
import {timingSafeEqual} from 'crypto';

export function checkPassword(candidate: string): boolean {
  const expected = process.env.ADMIN_PASSWORD;
  if (!expected) return false;

  const candidateBuffer = Buffer.from(candidate);
  const expectedBuffer = Buffer.from(expected);
  if (candidateBuffer.length !== expectedBuffer.length) return false;

  return timingSafeEqual(candidateBuffer, expectedBuffer);
}
```

// src/lib/crm/schema.ts
import {sql} from '@vercel/postgres';

let schemaReady: Promise<void> | null = null;

/**
 * Memoized per server instance — CREATE TABLE IF NOT EXISTS is safe to call
 * repeatedly, but there's no reason to round-trip to Postgres on every CRM
 * call when a cold start only needs to do this once.
 */
export function ensureSchema(): Promise<void> {
  if (!schemaReady) {
    schemaReady = runMigrations();
  }
  return schemaReady;
}

async function runMigrations(): Promise<void> {
  await sql`
    CREATE TABLE IF NOT EXISTS clients (
      id SERIAL PRIMARY KEY,
      name TEXT,
      phone TEXT,
      email TEXT,
      visit_type TEXT NOT NULL CHECK (visit_type IN ('studio', 'home', 'both', 'corporate')),
      status TEXT NOT NULL CHECK (status IN ('browsing', 'inquiry', 'booked', 'active', 'lapsed')),
      source TEXT NOT NULL,
      next_follow_up_at DATE,
      next_follow_up_note TEXT,
      created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
      updated_at TIMESTAMPTZ NOT NULL DEFAULT now()
    )
  `;

  await sql`
    CREATE TABLE IF NOT EXISTS packages (
      id SERIAL PRIMARY KEY,
      client_id INTEGER NOT NULL REFERENCES clients(id) ON DELETE CASCADE,
      label TEXT NOT NULL,
      total_sessions INTEGER NOT NULL,
      used_sessions INTEGER NOT NULL DEFAULT 0,
      price_paid NUMERIC(10, 2),
      payment_method TEXT CHECK (payment_method IN ('revolut', 'sumup', 'payment_link', 'other')),
      purchased_at DATE NOT NULL DEFAULT CURRENT_DATE
    )
  `;

  await sql`
    CREATE TABLE IF NOT EXISTS activity_log (
      id SERIAL PRIMARY KEY,
      client_id INTEGER NOT NULL REFERENCES clients(id) ON DELETE CASCADE,
      note TEXT NOT NULL,
      created_at TIMESTAMPTZ NOT NULL DEFAULT now()
    )
  `;
}

import {ensureSchema} from './schema';
import type {CreateClientInput} from './leadMapping';
import type {Client, ClientStatus, VisitType} from './types';

export type {CreateClientInput};

type ClientRow = {
  id: number;
  name: string | null;
  phone: string | null;
  email: string | null;
  visit_type: VisitType;
  status: ClientStatus;
  source: string;
  next_follow_up_at: string | null;
  next_follow_up_note: string | null;
  created_at: string;
  updated_at: string;
};

function mapRow(row: ClientRow): Client {
  return {
    id: row.id,
    name: row.name,
    phone: row.phone,
    email: row.email,
    visitType: row.visit_type,
    status: row.status,
    source: row.source,
    nextFollowUpAt: row.next_follow_up_at,
    nextFollowUpNote: row.next_follow_up_note,
    createdAt: row.created_at,
    updatedAt: row.updated_at,
  };
}

export async function createClient(input: CreateClientInput): Promise<Client> {
  await ensureSchema();
  const {rows} = await sql<ClientRow>`
    INSERT INTO clients (name, phone, email, visit_type, status, source)
    VALUES (

// src/proxy.ts (after this task)
import createMiddleware from 'next-intl/middleware';
import {NextResponse, type NextRequest} from 'next/server';
import {routing} from './i18n/routing';
import {COOKIE_NAME, verifySessionToken} from './lib/crm/session';

const intlMiddleware = createMiddleware(routing);

export default async function proxy(request: NextRequest) {
  const {pathname} = request.nextUrl;

  if (pathname.startsWith('/admin')) {
    if (pathname === '/admin/login') {
      return NextResponse.next();
    }

    const token = request.cookies.get(COOKIE_NAME)?.value;
    const valid = await verifySessionToken(token);
    if (!valid) {
      return NextResponse.redirect(new URL('/admin/login', request.url));
    }

    return NextResponse.next();
  }

  return intlMiddleware(request);
}

export const config = {
  matcher: '/((?!api|_next|_vercel|icon|apple-icon|opengraph-image|.*\\..*).*)',
};

'use server';

import {cookies} from 'next/headers';
import {redirect} from 'next/navigation';
import {checkPassword} from '@/lib/crm/password';
import {COOKIE_NAME, MAX_AGE_SECONDS, createSessionToken} from '@/lib/crm/session';

export type LoginState = {error: string | null};

export async function login(_prevState: LoginState, formData: FormData): Promise<LoginState> {
  const password = String(formData.get('password') ?? '');

  if (!checkPassword(password)) {
    return {error: 'Wrong password.'};
  }

  const token = await createSessionToken();
  (await cookies()).set(COOKIE_NAME, token, {
    httpOnly: true,
    secure: true,
    sameSite: 'lax',
    maxAge: MAX_AGE_SECONDS,
    path: '/',
  });

  redirect('/admin');
}

  const totalSessions = Number(formData.get('totalSessions'));
  const pricePaidRaw = formData.get('pricePaid');
  const pricePaid = pricePaidRaw ? Number(pricePaidRaw) : null;
  const paymentMethodRaw = String(formData.get('paymentMethod') ?? '');
  const paymentMethod = (paymentMethodRaw || null) as PaymentMethod | null;

  if (label && Number.isFinite(totalSessions) && totalSessions > 0) {
    await addPackage(clientId, {label, totalSessions, pricePaid, paymentMethod});
  }

  revalidatePath(`/admin/clients/${clientId}`);
}

export async function incrementSessionAction(packageId: number, clientId: number): Promise<void> {
  await incrementUsedSessions(packageId, 1);
  revalidatePath(`/admin/clients/${clientId}`);
}
